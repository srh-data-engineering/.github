## How to use

1. Clone the repository for your current lecture topic
2. Open the **HTML file** in your browser — it is the interactive lecture guide with all diagrams, concept explanations, and hands-on instructions
3. Follow the hands-on section inside the HTML — each topic provides self-contained commands or a one-shot setup script

---

## Lab Requirements

- **OS:** Ubuntu 22.04 or above (VM recommended)
- **Tools:** Docker (installed automatically by setup scripts where needed), Python 3.10+
- Each repository's `README.md` lists the exact prerequisites for that topic
